# ScamRadar

ScamRadar is a project for detecting scam/fraudulent activity, combining a browser extension, backend API, and machine learning model.

## Project Structure

- `backend/` — API server and ML model artifacts
- `browser_extension/` — Browser extension client (scraping, UI, settings)
- `ml_model/` — Model training scripts and notebooks

## Getting Started

Refer to the setup instructions within each subdirectory for installation and usage details.
